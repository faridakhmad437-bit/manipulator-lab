# Manipulator Lab

Planar 2-link manipulator: forward kinematics, analytic inverse kinematics, reachability checks, Jacobian conditioning, Newton-based IK (via NMT), and (planned) trajectory planning on top of [Numerical Method Toolkit](https://github.com/faridakhmad437-bit/Numerical-Method-Toolkit) (pinned to `v1.0.0`).

Full design: [SPEC.md](SPEC.md).

## Conventions

- Units: metres, radians, seconds. World frame at the shoulder, x right, y up, CCW positive.
- `theta1` is absolute; `theta2` is relative to link 1.
- **Elbow-up = negative `theta2`**, elbow-down = positive `theta2`.
- Defaults: `l1 = 1.0 m`, `l2 = 0.8 m` (reach `0.2 <= r <= 1.8 m`).
- Unreachable targets return `reachable=False` with a `reason`; invalid inputs raise `ValueError`.
- A pose is singular when `|sin(theta2)| < 1e-6`; `condition_number` returns `inf` when the Jacobian is numerically rank-deficient.

```python
from manipulator_lab import PlanarArm, Branch, fk, ik_analytic, ik_newton, jacobian, condition_number

arm = PlanarArm()
result = ik_analytic(arm, (1.0, 0.5), Branch.ELBOW_UP)
print(result.reachable, result.theta, fk(arm, result.theta))

# Numerical IK: the initial guess decides the branch

print(num.converged, num.theta, num.iterations, num.branch)
```

## Experiments

```powershell
python experiments/run_conditioning.py          # writes docs/results/conditioning_*.{png,json}
python experiments/run_ik_comparison.py        # writes docs/results/ik_*.{png,json}
```

Each run writes its parameters and the measurement environment (Python, NumPy, OS, CPU, git commit) next to the results. The success criteria are written in the script's docstring before it is run, and the script exits with status 1 if one fails.

### Conditioning of the Jacobian (week 2)

`cond(J)` depends on `theta2` only: with `F = l1^2 + 2 l2^2 + 2 l1 l2 cos(theta2)` and `D = l1 l2 |sin(theta2)|`, `cond(J) = sigma1^2 / D` where `sigma1^2 = (F + sqrt(F^2 - 4 D^2)) / 2`. The map is therefore a set of concentric rings, and `cond(J)` diverges at both workspace boundaries (fully stretched, fully folded). The folded boundary is less severe than the stretched one at the same distance from the singularity.

Results and plots are regenerated by the script; commit the files it writes under `docs/results/` from the machine whose environment you want recorded.

### Newton IK vs analytic IK (week 3)

`ik_newton` runs NMT's `newton_system` on `F(q) = fk(q) - target` with this library's Jacobian. Failures are returned as structured results (`reason`), not raised. Findings recorded by `run_ik_comparison.py` (sandbox run; official files come from your machine):

- Away from singularities Newton matches the analytic solution (max angle difference 8.9e-16 rad, residual 7.8e-16 m, median 5 iterations).
- Convergence slows towards the outer boundary and becomes linear at the singular root (28 iterations vs 6 in the interior).
- **Limitation:** `default_initial_guess` does not reliably select the requested branch within about 0.3 m of the inner (folded) boundary. Pass `initial=` explicitly there.
- The pre-registered v1 criteria failed; the v2 criteria were written after seeing that failure (post hoc) and both are kept in the script.
