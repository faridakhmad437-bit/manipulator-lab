# Manipulator Lab

Planar 2-link manipulator: forward kinematics, analytic inverse kinematics, reachability checks, Jacobian conditioning, and (planned) Newton-based IK and trajectory planning on top of [Numerical Method Toolkit](https://github.com/faridakhmad437-bit/Numerical-Method-Toolkit) (pinned to `v1.0.0`).

Full design: [SPEC.md](SPEC.md).

## Conventions

- Units: metres, radians, seconds. World frame at the shoulder, x right, y up, CCW positive.
- `theta1` is absolute; `theta2` is relative to link 1.
- **Elbow-up = negative `theta2`**, elbow-down = positive `theta2`.
- Defaults: `l1 = 1.0 m`, `l2 = 0.8 m` (reach `0.2 <= r <= 1.8 m`).
- Unreachable targets return `reachable=False` with a `reason`; invalid inputs raise `ValueError`.
- A pose is singular when `|sin(theta2)| < 1e-6`; `condition_number` returns `inf` when the Jacobian is numerically rank-deficient.

### Conditioning of the Jacobian (week 2)

`cond(J)` depends on `theta2` only: with `F = l1^2 + 2 l2^2 + 2 l1 l2 cos(theta2)` and `D = l1 l2 |sin(theta2)|`, `cond(J) = sigma1^2 / D` where `sigma1^2 = (F + sqrt(F^2 - 4 D^2)) / 2`. The map is therefore a set of concentric rings, and `cond(J)` diverges at both workspace boundaries (fully stretched, fully folded). The folded boundary is less severe than the stretched one at the same distance from the singularity.

Results and plots are regenerated by the script; commit the files it writes under `docs/results/` from the machine whose environment you want recorded.
